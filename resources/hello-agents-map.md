## How to use

1. Follow the stages in this repo for practice and checkpoints.
2. When a stage says “deep dive”, open the matching Hello-Agents chapter (or PDF).
3. Do not try to finish every chapter before building; alternate reading and small projects.
4. Prefer the English README and online site if Chinese is a barrier; the code is language-agnostic.

This keeps the best of both worlds: a clear India-oriented map + the deepest open Chinese/English agent tutorial available.
