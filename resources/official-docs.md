# Official Docs and Canonical Sources

Always prefer these over social-media tutorials.

## Core model & platform docs

- [Anthropic docs](https://docs.anthropic.com) – Claude, tool use, agents, prompt engineering
- [OpenAI Platform docs](https://platform.openai.com/docs) – models, tools, assistants, evals
- [Google AI / Gemini docs](https://ai.google.dev) – Gemini API, function calling
- [Ollama](https://ollama.com) – local models, easy CLI & API
- [Model Context Protocol (MCP)](https://modelcontextprotocol.io) – tool interoperability standard

## Frameworks & agent libraries

- [LangGraph](https://langchain-ai.github.io/langgraph/) – graph-based agent workflows
- [LangChain](https://python.langchain.com) – broader ecosystem
- [LlamaIndex](https://www.llamaindex.ai) – RAG & data agents
- [HelloAgents](https://github.com/jjyaoao/helloagents) – framework that matches the Hello-Agents tutorial

## Canonical learning references

- [Hello-Agents (Datawhale)](https://github.com/datawhalechina/hello-agents) – systematic tutorial
- [Hello-Agents online reading](https://datawhalechina.github.io/hello-agents)
- [Hello-Agents PDF releases](https://github.com/datawhalechina/hello-agents/releases/latest)
- [Agent Learning Hub](https://github.com/datawhalechina/Agent-Learning-Hub)

## Validation & engineering tools

- [Pytest](https://docs.pytest.org)
- [Pydantic](https://docs.pydantic.dev)
- [FastAPI](https://fastapi.tiangolo.com)
- [Git](https://git-scm.com/doc)

## How to use this list

1. When a stage says “read the official docs”, start here.
2. Prefer the provider you are actually using.
3. Cross-check any third-party tutorial against these sources.
