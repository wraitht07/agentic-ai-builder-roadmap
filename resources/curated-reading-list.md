# Curated Reading List

Prioritize official sources and the two mapped tutorials. Avoid social-media loops as primary learning.

## Beginner-friendly (start here)

- [Hello-Agents](https://github.com/datawhalechina/hello-agents) – systematic tutorial (Chapters 1–4 first)
- [Hello-Agents PDF latest](https://github.com/datawhalechina/hello-agents/releases/latest)
- [Anthropic – Building effective agents](https://www.anthropic.com/research/building-effective-agents)
- [OpenAI Platform docs](https://platform.openai.com/docs)
- [Ollama docs](https://ollama.com)
- Stage 0–2 practices in this repo

## Intermediate (after first agent loop)

- Hello-Agents Chapters 8 (Memory & RAG) and 9 (Context Engineering)
- [Model Context Protocol](https://modelcontextprotocol.io)
- Tool-calling sections of OpenAI / Anthropic / Google AI docs
- Stage 3, 6, 7 in this repo
- Production patterns from awesome-agentic-ai-zh Stage 7

## Advanced / production

- Hello-Agents Chapter 12 (Evaluation) + Chapter 10 (MCP / A2A protocols)
- Agent evaluation frameworks and LLM-as-judge patterns
- Multi-agent design (Hello-Agents Chapters 13–15 as case studies)
- Domain workflow design for MSME / GovTech / plant SOPs (this repo’s Phase 5)

## Suggested order for this roadmap

1. LLM basics (tokens, context, attention) – Stage 1 + Hello-Agents Ch. 3
2. Tool use and first agent loop – Stage 3 + Hello-Agents Ch. 4
3. RAG and context engineering – Stage 6 + Hello-Agents Ch. 8–9
4. Evaluation and hallucination detection – Stage 7 + Hello-Agents Ch. 12
5. Domain-specific workflow design – Phase 5 projects

## Extra high-value notes from Hello-Agents

- Extra01 – Agent interview questions (placement prep)
- Extra05 – Agent Skills vs MCP
- Extra09 – Practical pitfalls when building code agents

Keep this list short. When in doubt, open the official doc or the matching Hello-Agents chapter before searching social media.
