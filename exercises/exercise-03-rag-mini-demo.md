# Exercise 03: RAG Mini Demo

## Goal

Test whether retrieval helps answer a question grounded in a document set.

## Instructions

1. Create a tiny knowledge base with 5 to 10 short documents
2. Ask a question that requires using those docs
3. Compare:
   - raw prompt without retrieval
   - retrieval-based answer
4. Note the difference in factual grounding

## Reflection questions

- Which answer was more grounded?
- Did the model hallucinate when retrieval was missing?
- Which context was more relevant?

## Deliverable

A 1-page comparison note with example answers and comments.
