# Exercise 04: Agent Evaluation

## Goal

Create a rubric and evaluate an agent output.

## Instructions

1. Generate a short answer using an agent or model
2. Define a rubric for:
   - correctness
   - grounding
   - completeness
   - unsupported claims
3. Score the answer
4. Identify the weakest part and propose a fix

## Deliverable

A short evaluation sheet with scores and notes.
