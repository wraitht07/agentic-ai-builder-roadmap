# Exercise 01: Hello LLM

## Goal

Use a basic LLM call and inspect the output.

## Instructions

1. Pick a small model or API provider
2. Send a simple prompt
3. Compare results across prompts with small changes
4. Note differences in wording, confidence, and style

## Questions to reflect on

- Did the model respond consistently?
- Did the model use the same meaning across different phrasings?
- Did the answer include unsupported details?

## Deliverable

A short note explaining the model behavior in plain language.
